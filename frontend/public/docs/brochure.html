Pull vulnerabilities (severity: medium+) and compliance checks from Tenable.io via pyTenable SDK with delta pulls.

Tenable findings auto-update 26+ NIST 800-53 controls: open vulns flag Non-Compliant, fixed vulns restore Compliant.

3. Generate Policies

GPT-5.2 creates formal remediation policies from critical findings with 6 sections: Purpose, Scope, Statements, Remediation, Verification, Roles.

4. Create POA&M

Auto-generate Plan of Action & Milestones with severity timelines, CVE references, mapped controls, and status tracking.
