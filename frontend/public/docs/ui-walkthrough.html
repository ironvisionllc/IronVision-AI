IronVision AI — UI Walkthrough Guide

Complete feature guide | Version 2.1 | April 2026

1. Getting Started

1

Login

Navigate to the login page. Use Quick Demo Access buttons (DemoAdmin / DemoUser) for immediate access, or enter credentials. DemoAdmin has full CRUD; DemoUser is read-only.

2

Dashboard

The Command Center Dashboard shows customizable widgets: Framework Coverage, Risk Heatmap, Compliance Trend, Control Effectiveness, Quick Actions. Toggle visibility and reorder via settings.

2. Compliance Frameworks

3

Framework Grid

Sidebar > Frameworks — View all 14 frameworks as cards. Use Organize to reorder/hide. Click View Details to enter the Framework Workspace.

4

Framework Workspace

All controls with compliance status. Features: AI Assess All (GPT-5.2 auto-assessment), expand controls for SIEM evidence, Link Document, AI Coverage Analysis, search & filter.

3. Frameworks Action Bar

5

Evidence Collection

Click Evidence Collection → Run Collection to auto-gather evidence from 6 sources: SIEM, Tenable, pipelines, policies, assessments, checklists. View artifacts and per-framework coverage.

6

Policy-as-Code

Paste a JSON config and click Run Policy Evaluation. 8 built-in rules check encryption, MFA, TLS, secrets, tagging. Results show violations with mapped framework controls. Tabs: Evaluate, Rules, Drift, History.

7

Risk Scoring

Dynamic risk dashboard: org-wide score (0-100) from 5 weighted factors. Active alerts (SIEM, pipeline, compliance). Per-framework risk scores. Risk trend history.

8

DevSecOps Pipeline

Manage CI/CD compliance. Generate API keys for CI/CD tools. View pipeline runs with risk scores and gate results (Pass/Warn/Fail). Click a run for individual findings.

9

Ingestion Layer

Upload external checklists: STIG (XML), CIS (YAML/CSV), PCI (JSON), OSCAL (JSON), questionnaires. Click AI Auto-Map to map to frameworks. View Control Graph, Overlaps, SIEM Status tabs.

4. Tenable VM Integration

10

Tenable Dashboard

Sidebar > Integrations > Tenable VM > Open Dashboard — Five tabs: Dashboard, Vulnerabilities, Compliance Checks, POA&M, Settings.

  1. Settings — Enter Tenable.io access_key and secret_key, or click "Load Demo Data" for simulated dataset
  2. Sync Now — Pull vulnerability and compliance data (delta pull — only new/changed)
  3. Auto-Assess NIST Controls — Updates 26+ NIST 800-53 controls based on scan evidence
  4. Generate Remediation Policies — GPT-5.2 creates formal policy documents for each finding area
  5. Generate POA&M — Creates entries: Critical 15d (P1), High 30d (P2), Medium 90d (P3)
  6. POA&M Tab — Track entries: Open → In Progress → Completed / Delayed

5. Policy Center

11

Policy Templates

Sidebar > Policies — Browse 10 templates. Answer Org Questionnaire and generate AI policy content. Supports Version Control (snapshots, diff, restore) and Approval Workflow (Draft → Under Review → Approved).

12

Upload & Map + Document Library

Three upload modes: Map to Framework, General Upload, Create Document (built-in text editor). Document Library shows unified view with search, type/status/category filters, click-to-view, and approval workflow.

6. Other Features

13

SIEM Dashboard

Sidebar > SIEM — Live security events across 7 categories. Start simulator for realistic events. View event details and framework control mappings.

14

Compliance Copilot & Command Palette

AI assistant (bottom-right) for compliance questions via GPT-5.2. Cmd+K opens Command Palette for quick navigation.

Pro Tip: Ultimate compliance automation: (1) Sync Tenable, (2) Auto-Assess NIST controls, (3) Generate POA&M, (4) Generate remediation policies, (5) Run Evidence Collection, (6) Export OSCAL assessment results for auditor.
