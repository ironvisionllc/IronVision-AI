IronVision AI — UI Walkthrough Guide

Complete feature guide | Version 2.0 | April 2026

1. Getting Started

1

Login

Navigate to the login page. Use the Quick Demo Access buttons (DemoAdmin or DemoUser) for immediate access, or enter your email and password. The DemoAdmin account has full CRUD permissions; DemoUser is read-only.

2

Dashboard

After login, you land on the Command Center Dashboard. It shows 5 customizable widgets: Framework Coverage, Risk Heatmap, Compliance Trend, Control Effectiveness, Overdue Tasks, Upcoming events, and Quick Actions. Toggle widget visibility and reorder them using the settings icon.

2. Compliance Frameworks

Navigate via Sidebar > Frameworks

3

Framework Grid

View all 14 compliance frameworks as cards showing name, control count, and effectiveness score. Use Organize to reorder or hide frameworks. Click View Details to enter the Framework Workspace.

4

Framework Workspace

The workspace shows all controls for a framework with compliance status (Compliant / Partial / Non-Compliant / Not Assessed). Features include:

  1. AI Assess All — GPT-5.2 analyzes SIEM data and policies to auto-assess all controls
  2. Expand a control — View SIEM evidence, notes, policy suggestions, and implementation guidance
  3. Link Document — Attach any document from your library to a control
  4. AI Coverage Analysis — Analyze how well a linked document covers a control's requirements
  5. Search & filter — By status, category, or text search

3. Action Bar — Advanced Features

The Frameworks page header contains 7 action buttons:

5

Evidence Collection

Click Evidence Collection to open the automated evidence engine. Click Run Collection to auto-gather evidence from 5 sources: SIEM snapshots, pipeline scan reports, approved policy documents, compliance assessments, and ingested checklist mappings. View artifacts, check per-framework coverage, and track evidence freshness.

6

Policy-as-Code

Click Policy-as-Code to evaluate infrastructure configs against 8 built-in compliance rules. Paste a JSON config (Terraform output, K8s manifest, etc.) and click Run Policy Evaluation. Results show violations with severity, mapped framework controls, and remediation. Tabs: Evaluate Config, Policy Rules, Drift Detection, History.

7

Risk Scoring

Click Risk Scoring for the dynamic risk dashboard. See your org-wide risk score (0-100) computed from 5 weighted factors. View active alerts (SIEM events, pipeline failures, non-compliant controls), per-framework risk scores, and risk trend history.

8

DevSecOps Pipeline

Click DevSecOps Pipeline to manage CI/CD compliance integration. Generate API keys for your CI/CD tools (GitHub Actions, GitLab CI, Jenkins). View pipeline run history with risk scores and gate results (Pass/Warn/Fail). Click a run to see individual findings with CWE/CVE references.

9

Ingestion Layer

Click Ingestion Layer to upload external compliance checklists. Supported formats: STIG (XML), CIS (YAML/CSV), PCI DSS (JSON), OSCAL (JSON), and generic questionnaires. After upload, click AI Auto-Map to map ingested controls to existing frameworks. View the Control Graph, Framework Overlaps, and SIEM Status tabs.

4. Policy Center

Navigate via Sidebar > Policies

10

Policy Templates (Tab 1)

Browse 10 pre-built templates. Click a template to view details, answer the Org Questionnaire, and generate AI-powered policy content. Generated policies support Version Control (snapshots, diff, restore) and Approval Workflow (Draft → Under Review → Approved).

11

Upload & Map (Tab 2)

Three upload modes: Map to Framework (select frameworks + upload), General Upload (no framework), Create Document (built-in text editor). Supports PDF, DOCX, TXT, MD, and more.

12

Document Library (Tab 3)

Unified view of all policies, uploaded docs, and created documents. Click any document to view details, edit tags, manage approval status. Filters: Search, Type, Status, Category.

5. Other Features

13

SIEM Dashboard

Navigate via Sidebar > SIEM. View live security events with a simulated SIEM feed covering 7 categories. Start the simulator to generate realistic events. View event details and framework control mappings.

14

Compliance Copilot

Click the AI assistant button (bottom-right) to ask compliance questions in natural language. Powered by GPT-5.2, it can explain controls, suggest policies, and provide implementation guidance.

15

Command Palette

Press Cmd+K (or Ctrl+K) to open the Command Palette. Quickly navigate to any page, search frameworks, or trigger actions.

Pro Tip: For the best compliance workflow, start with the SIEM simulator (to generate events), then run AI Assess All on your frameworks, then use Evidence Collection to auto-gather everything for your audit.
