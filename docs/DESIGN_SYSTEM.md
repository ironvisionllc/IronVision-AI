# IronVision Design System

## Brand
- Product name: **IronVision AI**. Tagline: *Intelligent Risk. Continuous Assurance.* Internal codename `aegisrmf` (identifiers only).
- Logo source: the official customer artwork `frontend/src/assets/brand/original/Logo-01.webp` (vertical lockup: teal labyrinth shield with keyhole, plus the IRON/VISION wordmark, on a transparent background).
- `scripts/build_brand_assets.py` (Pillow + numpy) builds every variant from that one file: `logo-mark` (colour), `logo-mark-dark` (keyhole lightened), `logo-mark-mono` (white), `logo-lockup` and `logo-lockup-dark` (IRON #e2e8f0 / VISION #45aec7). Each comes as a master PNG plus 1x/2x sizes for `srcset`. It also builds the favicons (`favicon.svg`, 16, 32, 180 apple-touch, 512).
- Single swap point: `frontend/src/assets/brand/index.ts`. When the official vector arrives, point these exports at the SVG files.
- `BrandMark` (header) shows the colour mark in light theme and the white mono mark in dark theme. `BrandLockup` (login hero) shows the colour or dark lockup by theme, next to the "AI" product label and the tagline.

| Dark | page `linear-gradient(135deg,#0f172a,#1e293b)`, cards rgba(30,41,59,.8), borders rgba(51,65,85,.5), text #e2e8f0 |

Tailwind colour families resolve to `--c-<family>-<shade>` RGB variables:
- slate/gray → neutrals
- blue/sky/teal/cyan/indigo → brand
- rose/red/orange → coral/red
- amber/yellow → gold
- emerald/green → emerald
- violet/purple → violet

In dark mode the light tints (50–300) become tinted dark surfaces and the dark shades (700–950) become light text. Existing utility classes therefore work in both themes. `brand-*` holds the fixed hex values, used for elements that must not invert.

## Typography
Display 3rem/800/-0.03em · Headline 2rem/700/-0.025em · Title 1.25rem/600/-0.015em · Body 0.9375rem/400/1.7 · Caption 0.8125rem/500 · Label 0.6875rem/700/uppercase/0.1em (`.t-*` classes). Headings use Plus Jakarta Sans and body text uses Inter. Fallback stack: `ui-sans-serif, system-ui, -apple-system, Segoe UI, Roboto`.

Air-gapped deployments: `scripts/vendor_fonts.sh` writes `frontend/public/fonts/*.woff2` and `fonts.css` (already committed). Replace the two Google Fonts `<link>` tags in `frontend/deploy/index.html` with `<link rel="stylesheet" href="/fonts/fonts.css">`.

## Components
- Cards: `.panel` (radius 1rem, subtle shadow, no hover motion). `.card-interactive`, only on clickable cards: 3 px brand gradient top accent, −2 px lift, and a brand glow on hover/focus.
- Buttons (radius .625rem):
  - `.btn-primary`: gradient #2597B2→#1B839F; on hover #1B839F→#15697f with a stronger shadow.
  - Variants: `.btn-secondary`, `.btn-outline`, `.btn-ghost`, `.btn-destructive`.
  - Disabled buttons are dimmed and desaturated. Disabled-reason tooltips are kept.
- Navigation: active item has a 3 px left brand border and rgba(37,151,178,.1); hover uses .06. The light theme uses a light sidebar surface and the dark theme a translucent slate sidebar.
- Status (`StatusPill` / `S`): each pill shows text, colour and an icon.

  | Category | Colour | States |
  |---|---|---|
  | Draft | gold, dashed | draft |
  | Under Review | brand | in review, closure/risk-acceptance review, pending, submitted |
  | Approved | emerald | approved, passing, current, satisfied, implemented, closed … |
  | Failed | red | failing, failed, rejected, other than satisfied, integrity/signature mismatch |
  | Critical | coral | critical, high, open, expired, overdue |
  | Warning | gold | planned, partially implemented, near expiration, unmapped, needs attention |
  | Informational | teal | inherited, in progress, processing, risk accepted, false positive |

  Separate dimensions keep a small uppercase prefix: `IMPLEMENTATION:`, `ASSESSMENT:`, `MONITORING:`, `EVIDENCE FRESHNESS:`. `Sev` renders CAT I (critical) / CAT II (warning) / CAT III (informational).
- Modals (`Modal`) and the control drawer (Radix Dialog): themed popover surface, overlay token, Escape to close, focus moved into the dialog, `aria-modal`.
- Charts: Recharts strokes, grid and axes use `--iv-chart-*` tokens and recolour per theme.

## Accessibility
- Text tokens are chosen for WCAG AA in both themes. Light muted text is #475569/#5b6b80/#66758A on #FAFBFC, at 4.6–7.5:1.
- Brand focus ring on every focusable element (`:focus-visible`).
- `prefers-reduced-motion` disables the hover lift and transitions.
- The layout is desktop-first and works down to tablet widths (1024 px). The header hides secondary items progressively.

## Security headers for the SPA
- Production (`frontend/deploy/nginx.conf`):
  - CSP: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' data: https://fonts.gstatic.com; …; frame-ancestors 'none'`.
  - Also sent: `X-Content-Type-Options`, `X-Frame-Options DENY`, `Referrer-Policy no-referrer`, `Permissions-Policy`.
  - `location = /metrics` returns 404. Metrics are only at `/api/v1/metrics`, and the edge denies that path publicly.
  - The Docker build sets `INLINE_RUNTIME_CHUNK=false` so the strict `script-src 'self'` holds.
- Dev server / preview pod (`craco.config.js`):
  - Sends the same headers. The CSP is relaxed only for Emergent preview tooling scripts and for HMR websockets.
  - `frame-ancestors` comes from `DEV_FRAME_ANCESTORS`. The pod sets it to the Emergent preview hosts so the preview panel can embed the app. The default is `'none'`.
  - `/metrics` returns 404.
